## Клиент

1. Java 21.
2. `java -jar neoforge-21.1.265-installer.jar` → Install client.
3. Распаковать `mods`, `config`, `kubejs` из клиентского архива в `.minecraft`.

## Сервер

1. Java 21.
2. В папке `server/`: `java -jar neoforge-21.1.265-installer.jar --installServer`.
3. Запуск: `./start.sh` (Linux/macOS) или `start.bat` (Windows).

## Репозиторий

- `index.html` — сайт (GitHub Pages).
- `server/` — серверная сборка в распакованном виде.
- Релизы — клиентский и серверный архивы.
